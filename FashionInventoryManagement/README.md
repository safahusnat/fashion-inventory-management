# Fashion Inventory Management System

A full-stack C# ASP.NET Core MVC project for managing fashion inventory, stock levels and product categories.

## Features

- Add, edit and delete fashion inventory items
- Search items by name or brand
- Filter by category
- Track stock quantity and low-stock alerts
- View total item count, low-stock count and stock value
- SQLite database using Entity Framework Core

## Technologies Used

- C#
- ASP.NET Core MVC
- Entity Framework Core
- SQLite
- HTML/CSS
- Bootstrap

## Why I Built This

This project was created to demonstrate software engineering skills including CRUD functionality, database integration, MVC architecture, validation, clean code structure and version control.

## How To Run

1. Install .NET 8 SDK
2. Open the project in Visual Studio or VS Code
3. Run:

```bash
dotnet restore
dotnet run
```

4. Open the local host URL shown in the terminal.
